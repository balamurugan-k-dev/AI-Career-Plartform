AI Career & Job Intelligence Platform

An AI-powered career platform that helps users analyze resumes, discover suitable job roles, understand required skills, identify skill gaps, and explore job-related information.

🚀 Features

- 📄 Resume upload and analysis
- 🔍 Job role search
- 🧠 AI-powered resume insights
- 🎯 Resume-to-job skill matching
- 📊 Skill gap analysis
- 💼 Job requirements by experience level
- 💰 Salary range information
- 🏢 Company and job information
- 👤 User authentication
- 🛠️ Admin dashboard
- 📱 Responsive and professional UI

🛠️ Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas
- Gemini API
